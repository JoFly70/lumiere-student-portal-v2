## Pair decisions (RUT)

There is no RUT degree-architecture master among the byte-exact files. Layout inspection (sheet names and headers only):

- `rut-execution-final-v2-1.xlsx` (5 sheets: START HERE, WEEK BY WEEK, SOPHIA TRACKER, STUDY.COM TRACKER, DASHBOARD) is a student 3-month tracker with per-course challenge / milestone counts.
- `rut-orientation-v3-1.xlsx` (7 sheets: START HERE, THIS WEEK, WEEK BY WEEK, SOPHIA TRACKER, STUDY.COM TRACKER, DASHBOARD, LUMIÈRE HUB) is the orientation-phase version of the same family.

Neither carries degree requirements, credit placement or prior history, so neither can act as a true "master". Both orientations were run: orientation as master + final as companion, and final as master + orientation as companion, plus each alone. The final-v2-1 file is the better *execution* candidate (it is later); the orientation file is the better *master* candidate only because it is a superset of sheets. This is a stop-gap: the RUT plan needs the LOCKED working plan (BA Liberal Studies degree architecture), which was not obtained byte-exactly (see MANIFEST.md).

## Headline findings (baseline importer, before any S10 fix)

1. **`eph-master-validated-locked.xlsx` is unreadable.** The package uses the `x:` XML namespace prefix (`<x:workbook>`, `<x:worksheet>`); ExcelJS fails with `Cannot read properties of undefined (reading 'sheets')`; the importer reports a single blocking `UNKNOWN_TEMPLATE`. No sheet of the locked master reaches an adapter.
2. **`rut-orientation-v3-1.xlsx` is unreadable.** ExcelJS fails with `Cannot read properties of undefined (reading 'anchors')` (a drawing part). Importer: blocking `UNKNOWN_TEMPLATE`.
3. **The EPH execution workbook is recognised only as a lane grid.** Of 9 sheets only `WEEK BY WEEK` is read, and it contributes week windows (42 weeks starting 2026-09-14) but **0 courses and 0 tasks**: the real grid puts work in free-text lane cells ("Course A/B/C") and the due column is "Due this week"; the reconstruction expected per-assignment "Paper due" cells. The tracker sheets (EXTERNAL TRACKER, TECEP TRACKER, TESU RESIDENCY, COMPLETED CREDITS) have no recognised header and are ignored. Alone it produces no content (blocking `UNKNOWN_TEMPLATE`).
4. **EPH master (final) imports, but with serious mis-reads.** 36 items, of which many are total/note rows read as courses (provider text such as totals lines), 105 rows skipped, 13 `INVALID_CREDITS`, 13 `UNMAPPED_COLUMN`; `Master Plan` and `Validation` ignored. The companion merge added **0** execution data (0 dated tasks, 0 planned ends) and flagged **0** unmatched rows — nothing was surfaced to staff about the 42 weeks of scheduled work that was not merged.
5. **RUT final-v2-1 imports nothing.** Only `WEEK BY WEEK` is read (13 rows), 0 courses; the tracker sheets are ignored.
