## Pair decisions

**EPH.** The execution workbook follows the **validated-locked** master (23 remaining courses, 5 TECEP, 5 TESU residency, 0 Coopersmith); the "final" master is a different, superseded plan (7 TECEP, 7 Coopersmith, 2 TESU courses). Locked + execution is the correct pair; final + execution is run to show that substitutions surface as staff exceptions. Details: `reconciliation-EPH.md`.

**RUT.** There is no RUT degree-architecture master among the byte-exact files. `rut-execution-final-v2-1.xlsx` (5 sheets) and `rut-orientation-v3-1.xlsx` (7 sheets) are two revisions of the same 3-month tracker (13 Sophia + 5 Study.com courses, 54 credits). Neither has degree requirements, placement or prior history, so neither can be a true "master". Decision: import the tracker **execution-only** (`lumiere-execution-v1`, which states that degree structure and prior history are missing); the later `final-v2-1` is the primary file; `orientation-v3-1` as master + `final-v2-1` as companion (and the reverse) are run to exercise the merge. The RUT "locked working plan" (the real degree master) was not obtained byte-exactly and stays an open input.
